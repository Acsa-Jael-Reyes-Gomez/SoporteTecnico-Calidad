# Sistema de Tickets - Calidad de Software

## Descripción del proyecto

Este proyecto consiste en aplicar técnicas de aseguramiento de la calidad de software a un sistema de gestión de tickets de soporte técnico existente.

## Objetivo

Implementar un proceso de integración continua que permita ejecutar verificaciones automatizadas para evaluar la calidad del código y detectar posibles errores durante el desarrollo.

## Tecnologías del sistema

- Java
- HTML
- CSS
- Electron
- MySQL

## Actividades de calidad previstas

- Pruebas automatizadas.
- Análisis estático del código.
- Medición de cobertura de pruebas.
- Integración continua mediante GitHub Actions.
- Documentación y comparación de métricas de calidad.

## Estado del proyecto

Preparación del repositorio y planificación de las actividades de aseguramiento de la calidad.
